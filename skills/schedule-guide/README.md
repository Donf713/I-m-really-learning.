# 定时任务向导 · schedule-guide

从一句需求开始，逐轮帮助用户选方向或补充信息，合并历次需求，生成完整方案，确认后创建定时任务。

## 下载与使用

下载发布提供的 ZIP 并解压。也可以在 GitHub 仓库页面选择 **Code → Download ZIP**。

### 支持 Skills 的 Agent

将 `schedule-guide` 文件夹放进目标 Agent 文档规定的技能目录，保留 `SKILL.md`。技能发现或重新加载方式以该 Agent 为准。

Codex 的个人技能目录通常是 `~/.codex/skills/`；配置了 `CODEX_HOME` 时使用其下面的 `skills/`。安装后可以输入：

```text
使用 $schedule-guide，我想每天了解 AI 最新动态。
```

### 其他 Agent

把 `SKILL.md` 正文加入自定义指令，或上传文件并明确要求按照其中流程执行。例如：

```text
请加载附件 SKILL.md，按照定时任务向导流程帮我确定任务。
我的基本需求：每天了解 AI 最新动态。
```

`agents/openai.yaml` 是 Codex 界面元数据，其他 Agent 可以忽略。兼容范围取决于目标 Agent 是否能读取自定义指令；不保证所有产品都能自动发现技能。

## 交互流程

1. 输入基本需求，例如「每天看 AI 新闻」。
2. 选择一个方向，或者补充「关注电商应用」。
3. Agent 合并前后信息，提供更具体的方向，持续到需求明确。
4. 展示内容范围、输出格式、来源、执行提示词和时间安排。
5. 用户确认最终方案并授权创建，Agent 才使用所在平台的调度工具。

允许综合方向、多选、修改已有选择和仅生成方案。每轮只问一个主要问题，不要求填写长表格。

## 定时任务能力

本包是 Agent 行为指令，不是后台调度程序。实际运行依赖所在 Agent 的原生定时任务工具、可用数据访问能力和用户授权。没有调度工具时仍可完成需求引导与提示词生成，并明确报告尚未创建任务。

不包含账号凭据或 API 密钥。安装本技能不会创建任何实际定时任务，也不会自动向外部服务发送内容。

## 文件

- `SKILL.md`：核心流程和跨平台调度适配规则。
- `agents/openai.yaml`：Codex 的名称、简介和默认启动提示。
- `README.md`：下载、安装与兼容说明。
